生成AIなんでも共有会

実演プロンプト集

タップでコピー → Copilotに貼るだけ。
手元に文が無ければ「お題」を貼って試そう。

⚠️ 社外秘・個人情報は貼らないでください。お使いの環境のデータ取り扱い方針をご確認ください。迷ったら「お題」の例文を使ってください。
プロンプト（M365 Copilot / Outlook・Teams・Edgeサイドバー）
① メールを3行＋ToDoに要約
このメールを3行で要約して。あわせて「私がやること」を箇条書きで、期限があれば明記して。
② 返信の下書き（トーン指定）返信
このメールへの返信を、丁寧なトーンで作って。
・要点：（ここに伝えたいことを1〜2行）
・角が立たない言い回しで、120字程度で。
③ 会議メモを整理議事録
この会議メモを「決定事項／ToDo（担当・期限）／未決事項」の3つに分けて、表にまとめて。
お題（自分の文が無い人はこれを貼る）
貼る例文：長いメールお題
お疲れ様です。営業部の田中です。
先日ご相談した新製品説明会の件ですが、候補日をいくつか挙げます。
第一候補：7月10日(木)14時〜／第二候補：7月11日(金)10時〜／第三候補：7月14日(月)終日。
会場は本社3階の大会議室を仮押さえしていますが、オンライン併用も可能です。
つきましては、ご都合のよい日程を今週金曜(7月4日)までにご返信いただけますでしょうか。
当日の資料は前日までに共有します。参加人数も併せてお知らせいただけると助かります。
よろしくお願いいたします。
貼る例文：会議メモお題
じゃあ定例始めます。先月の数字は目標比98%でほぼ達成。
来月は新規キャンペーンを7月15日から走らせる方向で。
デザインは佐藤さんが今週中にラフ、来週レビュー。
問い合わせ対応、件数が増えてるので一次対応のテンプレを作りたい。これは鈴木さんお願い。
予算は来週の役員会で確認してから決定。次回は7月22日(火)14時から。
プロンプト（GitHub Copilot / VS Code Chat）
① コミットメッセージcommit
ステージ済みの差分から、Conventional Commits 形式で日本語のコミットメッセージを提案して。件名は50字以内、本文に「なぜ」を1〜2行で。
② テスト生成test
この関数のユニットテストを pytest で書いて。正常系・境界値・異常系に分けて、各ケースに日本語コメントを付けて。
③ レビュー一次チェックreview
この差分をレビューして。バグ・境界の抜け・未処理の例外・N+1 を指摘。重大度順に、修正案も一言添えて。
④ ドキュメント（docstring）doc
この関数のdocstringを日本語で書いて。引数・戻り値・発生しうる例外も明記して。
お題（自分のコードが無い人はこれを貼る）
貼る例：差分（diff）お題
- sma = sum(recent[-20:]) / 20
+ window = recent[-20:]
+ if len(window) < 20:
+     sma = sum(window) / len(window)  # 窓不足を平均でガード
+ else:
+     sma = sum(window) / 20
貼る例：関数お題
def discount(price, rate):
    if rate < 0 or rate > 1:
        raise ValueError("rate must be 0..1")
    return round(price * (1 - rate))
